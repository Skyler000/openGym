About WinterARC

WinterARC is a self-hosted gym and body-weight tracker. It runs on hardware you control, and your training data stays in a folder you own.

Every tracker worth using gets sharpened by being used. The guided workout flow, the weight pre-fills, the rest timer, the "ask my body weight before the first set" ritual — none of that comes from a feature list. It comes from standing in the gym with the thing in your hand and fixing whatever was awkward that evening.

What that has grown into: passkey profiles, so signing in is a fingerprint and everyone's data stays separate, and sync, so the log survives any phone. A proper React app in 12 languages, with a muscle map, ready-made training programs, importers for FitNotes, Strong, Hevy and Apple Health, and an Android build you can install yourself.

The AGPL license is the point, not a footnote: your training data should be yours, the software that holds it should be inspectable, and nobody — including whoever runs your instance — should be able to take a closed, paid version of it away from you.

— Skyler, maintainer · Skyler000/WinterARC

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving WinterARC must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The backend is one Node file with a single dependency; the frontend is React, a router and a store. Small enough to actually audit.
  • Open source that stays open. AGPL-3.0, so every fork and every hosted version owes its code back to everyone.
